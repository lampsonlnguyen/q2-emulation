Q2 Emulator for the web

The goal is to run Q2 firmware locally in your browser using QEMU and WebAssembly, without a desktop installation. MIPS runtime compatibility is still being investigated.

  1. Landing page and static hosting
  2. Compile and validate MIPS WebAssembly runtime
  3. Boot Linux and launch Q2 firmware
  4. Connect virtual controls, display and storage
Follow development

Get started on desktop

Download the desktop emulator, open your own firmware ZIP or update.tar, then use the virtual player. Audio playback and real radio hardware are not emulated; performance must be confirmed on physical hardware.
