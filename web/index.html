01 / RUNTIME

Actual firmware binaries

QEMU executes MIPS instructions rather than recreating the firmware interface in JavaScript.

02 / DEVICE

Virtual controls and storage

Desktop supports the wheel, buttons, display and virtual SD folder. Browser hardware integration is in development.
